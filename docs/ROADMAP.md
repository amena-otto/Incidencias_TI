# Roadmap
1. Base de importación TXT y texto pegado, reglas de clasificación, revisión y persistencia.
2. Catálogo de docentes importable desde Excel y coincidencia de nombres.
3. Correlación temporal de respuestas para contextualización; revisión humana siempre.
4. Dashboard web y filtros por fecha, docente y categoría.
5. Excel con dashboard de estilo Power BI.
6. OAuth Google Drive, selección de carpeta y subida directa.
7. Reportes diarios/semanales, deduplicación y pruebas automatizadas.
